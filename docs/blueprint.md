# **App Name**: Arcane Dossier: Character Tracker

## Core Features:

- User Account Management: Secure email and password sign-up and login using Supabase Auth, ensuring users only access their own private character data.
- Character Data Input: A comprehensive form for creating and updating character details (name, age, sex, appearance, role, descriptions), with client-side validation for a concise 5-word intro.
- Image Upload and Clipboard Paste: Seamless integration for uploading character images from local files and direct pasting of images from the clipboard into the character form.
- Character Card Gallery: Display a dynamic gallery of digital tarot-style character cards, each featuring an image, name, and a 5-word introduction with glowing borders.
- Detailed Character Dossier Modal: An interactive modal that appears on card selection, presenting a full breakdown of all character attributes, including age, detailed appearance data (jsonb), and trivia.

## Style Guidelines:

- Background color: Deep charcoal (#0a0a0c) to establish the dark mode 'Arcane Tech' theme, as specified.
- Primary interactive color: Vibrant Neon Violet (#8b5cf6), directly from the user's theme, for interactive elements, glowing borders, and key highlights.
- Accent color 1: Ethereal Blue-Violet (#7eb3ff), offering an analogous contrast to the primary, ideal for secondary highlights, subtle glows, and complementary text, maintaining an arcane-futuristic feel.
- Accent color 2: Luminescent Green (#39FF14), for status indicators, success messages, or specific magical effects, adding a vibrant contrast.
- Accent color 3: Mystic Pink (#FC7EFF), for rare item highlights, warnings, or feminine character elements, offering another vibrant, magical accent.
- Headlines and prominent text: 'Space Grotesk' (sans-serif), for a modern, techy, and slightly mysterious feel, perfectly suiting 'Arcane Tech'.
- Body text and detailed descriptions: 'Inter' (sans-serif), chosen for its excellent readability and neutral, modern aesthetic that complements 'Space Grotesk' in long-form content within the dossier.
- Utilize mystical or futuristic glyphs and subtle digital patterns for iconography, reinforcing the 'Modern Magic / Arcane Tech' theme without visual clutter.
- Main character view employs a responsive grid or masonry layout for the 'Digital Tarot Cards', with a distinct, focused modal view for the detailed 'Dossier' presentation.
- Incorporate subtle glowing, pulsing, or shimmering animations, especially around card borders and interactive elements, to emphasize the 'glowing borders' and 'arcane' feel. Smooth transitions for modal openings and card interactions.
